Colour tables copied unchanged from [Blender-Colormaps](https://github.com/TheJeran/Blender-Colormaps)
at commit `cc604aa8ca760065a4a68d46a00bfa92913ad619` (`assets/colormaps/`), which declares GPL-2.0-or-later in its
`blender_manifest.toml`. These are the collections with no suitable Python package, plus `scientific/naviaW.rgb`
(renamed from `naviaw.rgb`), which cmcrameri does not include.

`carbonplan/` is the exception: it is generated by `scripts/carbonplan/export.mjs`
(`npm install && npm run export` there) from `@carbonplan/colormaps` 4.0.0 (MIT), in
light and dark mode. The tables Blender-Colormaps ships are all dark mode, as
CarbonPlan's own export ignores the mode. A map that is the same in both modes is
written once, without a suffix (`rainbow`, `sinebow`).
The original terms of each collection have not been verified.
